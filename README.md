# External Quality Assurance Program
## Generating automated reports for statistical analysis of External Quality Control for Point-of-Care-Testing (PoCT) devices.
**Author**: Jana Omaiche

Welcome to my repository showcasing workplace projects. This repository consists of developing automated procedures for report generation, enhancing the operational efficiency and reliability of startistical data analysis processes using Python programming.
Each script contains the relevant information for each PoCT medical device.
